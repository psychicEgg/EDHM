# Hyperspace Mod v1.105.0 for Elite Dangerous 4.4.2.0

### by Fred89210<br><br>

**-- Ready for Elite Dangerous 4.4.2.0 --**<br><br>

**Release Notes:**
- Add Two new options for adjusting the intensity of various Hyperspace Tunnel Effects, allowing for customization of the animation *(see the second video for some examples)*
  - The `Extra Dark` Mode option has been removed, as setting the new `Hyperspace Dust Intensity` option to 0 achieves the same result
- Fix Hyperdiction Dectection
- Add an Extra Safety Measure to affect only Hyperspace Jump in Ship
- Starting with this version (v1.105.0), the Plugin includes Shaders, therefore you must **Close the Game** to install it otherwise the Mod will not work correctly


**Previous versions:**
- Now the Cockpit Lighting is separate from the HUD, so it's possible to turn one off and keep the other on
- Minor change to improve compatibility with other 3PMods
- Added several Keys and Combinations for Keybinds
- Improvement for EDHM-UI v3

-------------------------------------------------------------------------

**Description:**

This Mod Customize your Hyperspace Jumps.

Automatically Turn Off the HUD and Cockpit Lighting in Hyperspace, Disable the Light emitted by the Destination Star, or make Hyperspace Jumps Very Dark and Scary.

NOTE: This Mod does not affect ARX items, some Cockpit Night Lights and does NOT modify Fleet Carrier Jumps.<br>

If you encounter any issues with this mod, please contact me on the [EDHM Discord](https://discord.gg/KTYgJegfYw).<br>

The Plugin includes Shaders, therefore you must **Close the Game** to install it otherwise the Mod will not work correctly

-------------------------------------------------------------------------

**How to use:**

With EDHM_UI:

Go to `Main Menu -> 3PMods -> Hyperspace Mod` and Enable/Disable Options or change the Keys.<br><br>

Without EDHM_UI:

Edit `HyperspaceMod.ini`
