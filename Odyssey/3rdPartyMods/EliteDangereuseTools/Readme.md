# Elite Dangereuse Tools v1.0.0 for Elite Dangerous 4.4.1.1

### by Fred89210<br><br>

**-- Ready for Elite Dangerous 4.4.1.1 --**<br><br>

**Release Notes:**
- First Release

-------------------------------------------------------------------------

**Description:**

A Collection of Tools dedicated to the site [https://elitedangereuse.fr/](https://elitedangereuse.fr/en/index.php?spnsr=LPTR-9BZT).

This Collection of Tools requires the latest version of [EDHM](https://github.com/psychicEgg/EDHM/tree/main/Odyssey) and is compatible with [EDHM_UI](https://github.com/BlueMystical/EDHM_UI/releases).

The Tools currently available in this Collection:
- **Galactic Hunt**: With this Tool, you can submit Perfect Screenshots of the Celestial Bodies requested by the [Elite Dangereuse's Galactic Hunt](https://elitedangereuse.fr/en/galactic-hunt.php?spnsr=LPTR-9BZT).

-------------------------------------------------------------------------

**To Manage these Tools:**

With EDHM_UI:

Go to `Main Menu -> 3PMods -> Elite Dangereuse Tools`<br><br>
